# Reference contract
## Reference set
Rúbrica académica, implementación actual de React/Flutter/Spring y evaluación Keras v2. El usuario ofreció su VM Oracle y autorizó datos de demostración el 22-nov.
## Authority by dimension
Core: API Spring, JWT/RestaurantAccess y modelo exportado. Experiencia web: componentes React/Redux existentes. Capacidad: endpoints efectivos y roles; información de minería: report.json y model.json. Datos operativos del nuevo servidor: semilla sintética opt-in, sin migración de Railway.
## Reuse and deviations
Se preservan APIs y modelo. Nueva infraestructura aislada con Compose/Caddy; no se modifica el código ni los datos del otro sistema del host. Se hace pública sólo la lectura de categorías que ya acompaña al catálogo de comida; altas/ediciones/borrados siguen protegidos. Flutter reutiliza el mismo export para inferencia local por solicitud explícita.
## Coverage gates
Catálogo sin sesión, escritura administrativa anónima rechazada, cuatro roles, cinco predicciones cotejadas y cinco fotografías descargadas/decodificadas. Validación del build real y HTTPS; aceptación académica corresponde al equipo.
