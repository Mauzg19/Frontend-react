# Product
## Users and outcomes
Restaurant Fast permite consultar restaurantes/comida, comprar y operar un restaurante por roles. Este repositorio contiene React / catálogo / operación web.
## Scope
Despliegue académico en Oracle solicitado por el usuario, usando una base nueva con catálogo y cuentas de demostración, opción elegida explícitamente. Corregir catálogo público sin sesión; preservar administración, minería v2 y entregas anteriores.
## Acceptance
Web/API públicas con HTTPS válido, cinco fotos reales del proyecto, modelo v2 coherente entre API y app, accesos administrativos protegidos y datos persistentes separados del sistema previamente alojado. Stripe real y teléfono siguen aplazados; no simular que se efectuó un pago real.
